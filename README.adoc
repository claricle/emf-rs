= emf-rs

Rust workspace for the EMF/EMF+/WMF metafile parser — the native core
for the https://github.com/claricle/emf[emf] gem, mirroring the
https://github.com/parsanol/parsanol-rs[parsanol rust/ruby pair] structure.

== Crates

* `emf-core` — the record parser and typed record model
* `emf-ffi` — C ABI surface for the emf gem's binding
